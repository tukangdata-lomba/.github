# TUKANGDATA

Open-source write-ups and notebooks from the data science competitions we have entered. Each repository contains the final notebook, the code it depends on, a short method description and instructions to reproduce it. Competition data belongs to the organizers and is not redistributed.

| Competition | Task | Result | Repository |
|---|---|---|---|
| ACTION 2026 Data Mining (HIMASADA, Universitas Negeri Surabaya) | Multi-label sentiment classification of public-service complaints | 1st place | [action-2026-data-mining](https://github.com/tukangdata-lomba/action-2026-data-mining) |
| INCEPTION 2026 (HIMATIFA, UPN "Veteran" Jawa Timur) | Early warning system for IHSG realized volatility with explainable AI | 1st place | [inception-2026](https://github.com/tukangdata-lomba/inception-2026) |
| JOINTS x INSPIRE 2026 (Universitas Gadjah Mada) | Cinema ticket demand forecasting | 1st place | [joints-x-inspire-2026](https://github.com/tukangdata-lomba/joints-x-inspire-2026) |
| ISFEST 2026 Data Competition (UMN) | EV charging station utilization forecasting | 2nd place | [isfest-2026-datcom](https://github.com/tukangdata-lomba/isfest-2026-datcom) |
| NPC DSC 2026 (Schematics ITS) | Open-set bird chirp classification | 3rd place | [npc-2026](https://github.com/tukangdata-lomba/npc-2026) |
